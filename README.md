# CustomOutline

Client-side Fabric mod for Minecraft Java 1.21.11 that lets you fully customize the glowing entity outline: colors, effects, per-entity settings.

**Author:** NotHeartYT

## Features
- RGB sliders, HEX input and preset colors
- Separate profiles: Default, Players, Villagers, Animals, Mobs, plus any entity ID (Custom tab)
- Effects: Static, Rainbow, RGB Cycle, Breathing, with custom speed
- Brightness control, master on/off, option to keep vanilla team colors
- Dark/neon config GUI with live preview, Save and Reset buttons
- Settings saved to `config/customoutline.json`
- Client-only: works on any multiplayer server

## Open the settings
- Mod Menu, then CustomOutline, then Configure
- Or type `/customoutline` in chat

## Build
Push to GitHub, open the **Actions** tab, then **build**, then download the jar from the artifacts.
Requires Fabric Loader 0.18.1+, Fabric API, Java 21. Mod Menu is optional.
